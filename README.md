# 내 스캐너

휴대폰에서 종이 문서를 촬영하거나 사진을 선택하고, 네 모서리를 직접 지정해 원근을 보정한 다음 여러 페이지를 PDF로 저장하는 개인용 웹 앱입니다. Android와 iPhone에서 앱스토어 설치 없이 사용할 수 있습니다.

## 사용 방법

1. 휴대폰에서 앱 주소를 엽니다. **사진 촬영**을 누르거나 **사진 보관함에서 가져오기**를 누릅니다.
2. 네 개의 동그란 점을 종이의 모서리로 끌어 옮깁니다. 점의 순서는 왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래입니다.
3. 컬러, 흑백 또는 문서 보정을 선택하고 **페이지 추가**를 누릅니다. 추가 페이지가 있다면 같은 과정을 반복합니다.
4. 사진으로 저장하려면 각 페이지 아래의 **사진 저장**을 누르고 공유 메뉴에서 **이미지 저장** 또는 사진 앱을 선택합니다. 메뉴의 이름과 제공 여부는 기기에 따라 다릅니다. 공유 메뉴에 사진 저장 항목이 없다면 **JPG 다운로드**를 누른 다음 다운로드한 파일을 열어 사진 보관함에 저장하세요. Android에서는 사진 앱의 다운로드 폴더에 표시될 수 있습니다. iPhone에서는 파일 앱의 다운로드 폴더에서 이미지를 열고 공유 → 이미지 저장을 선택할 수 있습니다.
5. 여러 페이지를 한 파일로 보관하려면 **PDF 저장 또는 공유**를 누르고 공유 메뉴에서 파일 저장을 선택합니다. 공유 메뉴가 지원되지 않으면 PDF 다운로드를 시도합니다.

페이지는 추가된 순서로 PDF에 들어갑니다. 순서 변경은 지원하지 않으므로 필요하면 페이지를 삭제하고 원하는 순서대로 다시 추가하세요. 문서 경계는 자동으로 감지하지 않습니다. 문서 보정은 단순 흑백 처리여서 그림이나 흐린 글씨가 손실될 수 있습니다. 저장하기 전에 결과 썸네일을 확인해 주세요.

**페이지는 임시 메모리에만 있습니다.** 새로고침하거나 앱을 닫으면 사라지므로 반드시 사진이나 PDF를 저장하세요. 사진과 PDF는 기기 안에서 처리하며 서버로 전송하지 않습니다. OCR(글자 인식) 기능은 포함되지 않습니다.

## 휴대폰에서 사용하기: HTTPS 주소 만들기

이 폴더를 HTTPS로 제공하는 웹 서버에 올려야 합니다. 아래는 무료 GitHub Pages를 사용하는 예입니다. GitHub 계정과 인터넷 연결이 필요합니다. 공개 저장소를 사용하므로 **앱 파일만** 올리세요. 스캔 사진이나 PDF는 올리지 마세요. 사이트 방문 기록은 호스팅 서비스에 남을 수 있습니다.

1. GitHub에서 새 **Public** 저장소를 만듭니다.
2. 저장소에서 **Add file → Upload files**를 선택하고 이 폴더의 파일을 모두 저장소 최상위에 올립니다. `index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`가 같은 위치에 있어야 합니다. 이 설명 파일도 함께 올려도 됩니다.
3. 저장소의 **Settings → Pages**에서 **Build and deployment**를 **Deploy from a branch**, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하고 저장합니다.
4. Pages 설정 화면에 표시되는 `https://...github.io/.../` 주소가 준비되면 휴대폰 브라우저에서 엽니다. 처음 배포에는 시간이 걸릴 수 있습니다.
5. Android에서는 Chrome 메뉴의 **홈 화면에 추가** 또는 **앱 설치**를 선택합니다. iPhone에서는 Safari의 공유 버튼 → **홈 화면에 추가**를 선택합니다. 메뉴 이름은 기기와 OS 버전에 따라 다를 수 있습니다.

처음 주소를 열 때는 인터넷이 필요합니다. 정상적으로 한 번 열린 후에는 앱 파일이 기기에 저장되어 같은 기기에서 오프라인으로 열 수 있습니다. 브라우저의 저장 공간 삭제나 운영체제의 정리 때문에 캐시가 지워지면 인터넷 연결이 다시 필요합니다. 기기 및 브라우저 정책에 따라 오프라인 설치 동작은 다를 수 있습니다.

## 컴퓨터에서 확인하기

이 폴더에서 `node`가 설치된 환경이라면 정적 웹 서버로 제공해 확인할 수 있습니다. 단순히 `index.html`을 여는 방식은 설치와 오프라인 캐시를 지원하지 않습니다. 휴대폰에서 카메라/설치 기능을 안정적으로 사용하려면 HTTPS 주소가 필요합니다. 이 폴더는 서버 프로그램을 포함하지 않습니다.

## 주의

- 고해상도 원본은 처리 성능을 위해 긴 변을 최대 1,400픽셀로 줄인 뒤 보정합니다. 작은 글씨나 정밀 문서에는 부족할 수 있습니다.
- PDF 공유나 다운로드 동작은 브라우저와 기기 설정에 따라 다릅니다. 저장된 파일을 열어 확인하세요.
- 사진이 많으면 기기의 메모리가 부족할 수 있으므로 여러 PDF로 나누어 저장하세요.
- 앱을 수정해 다시 배포할 때는 `sw.js`의 캐시 이름을 변경해야 기존 기기에 새 파일이 적용됩니다.
